## 启动

需要 Node.js 20 或更新版本，无需安装业务依赖。

```powershell
cd D:\CodexWork\ai-ppt-studio
npm run dev
```

打开 http://127.0.0.1:4173 。双击 `启动网站.cmd` 也可启动。端口占用时设置 `$env:PORT=4174` 后重试。

## 版本边界

这一版落实网站框架与交互，**不是已具备实际营收能力的生产 SaaS**。

生成采用本地确定性场景模板，未调用 AI。短信和支付为显式标注的演示流程，不会发短信或收款。本地存储仅用于交互验收，不具备服务端身份鉴权、跨设备同步、生产计费一致性、安全隔离或后台角色权限。PPTX 导出没有接入 Presenton，也未完成 PRD 的 Presenton 20 份基准评估；当前仅以 PptxGenJS 验证前端导出。

当前文件、文本与演示数据均在浏览器内处理及保存；部署站点会正常加载网页资源，但不上传资料正文。请仅使用虚拟手机号和脱敏资料。刷新保留当前浏览器草稿；清空浏览器数据会丢失项目。不能把本地演示额度作为实际收费凭据。

## 后续服务接入

业务操作集中在 `dist/app.js` 的 `createOutline`、`startGeneration`、`finishJob`、`payment`、`refund`、`exportPptx`。正式版需拆分业务模块并替换为 PRD `/api/v1` 接口。模型、支付、短信密钥只能放在服务端。

后续需要完成：Presenton 固定版本评估及导出方案决策，Next.js/FastAPI 服务、PostgreSQL 迁移与事务台账、Redis/Celery Worker、资料隔离解析、短信防滥用、支付验签幂等、服务端内容审核及 AI 标识、安全与性能测试、适用的公众上线手续。

## 文件结构

```text
dist/index.html           页面入口
dist/app.js               路由、页面、状态、交互和导出
dist/styles.css           响应式布局与组件
dist/tokens.css           设计变量
dist/vendor/              本地 PPTX 和 PDF 组件
server.mjs                本地静态服务器
tests/e2e.cjs             浏览器流程回归
.openai/hosting.json      站点发布配置
```

`npm run check` 检查语法。回归脚本需要 Playwright 和 Chromium，当前环境使用 Codex 随附包；自有环境先安装 Playwright 并准备浏览器。先启动网站，再运行 `npm test`。

## 第三方组件

PptxGenJS 4.0.1（MIT，bundle 含 JSZip），PDF.js（Apache 2.0），相关许可证见 `dist/vendor`。站点视觉与幻灯片图形由项目自身 CSS 和原生 PPT 形状绘制，无远程字体、付费模板或生成图片依赖。

## 2026-10-18 界面与流程优化

- 创作首页突出需求输入，受众设置按需展开；说明大纲、生成、导出各自的额度规则。
- 模板预览与使用分开，支持 10 页结构预览、缩略目录、左右方向键、搜索及场景筛选。预览不创建项目、不扣额度。
- 生成改为逐页执行本地校验与整理，保存已完成页面；关闭浏览器暂停，重新打开续接。取消或失败释放冻结额度，重试可复用与当前大纲一致的结果。
- 编辑器内容缩略图实时更新，提供当前会话撤销、页码上下文、字数与真实存储状态；历史版本仍可恢复。撤销不会返还已使用的改写次数。
- 最近项目按更新时间排列，首页显示未完成任务入口。保持原有路由、存储键、套餐、导出及演示能力边界。

先运行 npm start，再使用 npm test、npm run test:ux、npm run test:edge。新增界面设计约定见 design.md，验收细节见验收记录.md。

## GitHub Pages 部署

源码仓库：https://github.com/Deeer233/ai-ppt-studio

发布内容仅为 dist 静态目录，部署分支为 gh-pages。首次部署由仓库 Pages 设置启用，后续更新先提交源码并推送 main，再运行 npm run deploy:pages。无需配置 AI、支付或短信密钥；演示账户与资料保存在访问者自己的浏览器中。

GitHub Pages 不运行 server.mjs，本地服务中的自定义响应头不随静态发布自动生效。当前站点仍为演示原型，不收款，不提供真实模型生成或云端保存。
